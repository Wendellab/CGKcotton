# External input layout

Processed datasets are not published in this code update. See [INPUTS.md](../docs/INPUTS.md) for filenames and expected folder structure. Point CGK_DATA_ROOT or argument 2 of 99_Supplemental/scripts/run_analysis.R to an external Ozcotton data directory. No raw reads, alignments, genotype matrices, f-statistic block arrays, or full R sessions are included.
