# 09_SpeciesDistribution

Australian native cotton distribution and Grandicalyx clade maps.

## Main code

- [distribution.R](distribution.R)
- [distribution_clades.R](distribution_clades.R)

## Plotting and summary tasks

Run from the repository root with the external input directory:

```bash
Rscript 99_Supplemental/scripts/run_analysis.R distribution /path/to/Ozcotton
Rscript 99_Supplemental/scripts/run_analysis.R distribution_clades /path/to/Ozcotton
```
